# DEEPDELL website: instructions for AI sessions

Static site on GitHub Pages (`main` deploys). English root pages are the source; `/fr /de /es /it /ar /ms /id` are generated by `tools/i18n_build.py` and never edited by hand. The blog (`/blog/`) is generated from `blog/posts/*.md` by `tools/gen_blog.py` (see `.claude/skills/blog/SKILL.md`).

## Deploy rule (mandatory)
Never merge or push to `main` until the pre-deploy gate passes, and only deploy when the user says "Deploy".

```
bash qa/predeploy.sh            # full gate: rebuild, security check, all-device responsive/UI/brand check
bash qa/predeploy.sh --quick    # same with 6 devices, for iterating
```

1. **Security and hack-proof check** (`qa/security.py`): secrets, unsafe JavaScript, third-party allow-list, exposed files, forms, Worker origin and rate limits, CI hygiene. Any FAIL blocks the deploy. Run `python3 qa/security.py --live` after deploying.
2. **Responsive, UI/UX and brand check** (`qa/responsive.js`): phones (including a folded foldable), tablets, laptops, desktop, QHD and 4K TV, portrait and landscape, English and Arabic RTL. Fails on horizontal scroll, header collisions, tiny tap targets, broken images, clipped text, low contrast, unlabeled fields, and brand drift (Manrope + DM Mono fonts, cyan `#24e4f2`, logo).
3. After the gate passes, look at the screenshots in `qa/out/` for the changed pages and fix anything that looks off.
4. After deploying, wait for the "DEEPDELL Production QA" workflow to pass and report the result.

Report gate results honestly: list any WARN items and anything not tested. A check cannot prove a site is unhackable; say what was checked.

## Private digital cards
Digital visiting cards for executives and referral/affiliate partners are private. Follow `.claude/skills/digital-card/SKILL.md`: ask for the person's details first, generate with `tools/digital_card.py` into `~/deepdell-private-cards/`, deliver the files to the user, and never commit, publish or link them from the website.

## Conventions
- Brand: dark navy, cyan `#24e4f2` accent, Manrope text, DM Mono labels, plain English, no specific client project names, no invented statistics or testimonials.
- Every visible string lives in the HTML so the translation pipeline picks it up. Add translations for new strings in all 7 languages.
- Bump the asset version (`?v=...`) whenever `script.js`, `site.css` or other shared assets change.
- Regenerate, never hand-edit generated files: `tools/gen_pages.py`, `tools/gen_tools.py`, `tools/gen_blog.py`, `tools/i18n_build.py`.
